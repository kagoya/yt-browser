3. 技術的な制約と注意

  1. GitHub PagesのHTTPS配信を推奨します。file:// ではWorkerやブラウザのオリジン制約で挙動が変わることがあります。
  2. 標準のWebページでは、WASMやPyodideもブラウザのCORSを回避できません。
  3. YouTube.jsは公式ガイドでブラウザ利用時に独自プロキシを要求しています。この実験はプロキシを使用しないため、失敗が十分予想されます。
  4. yt-dlpはPythonパッケージ自体を読み込めても、通信・外部JSランタイム・OS依存機能などで情報取得が失敗する場合があります。
  5. このページには動画のダウンロードやCanvas再生機能はありません。YouTubeの利用規約・権利条件を尊重してください。
